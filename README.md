This is a clean, modern solution to the [Social Links Profile challenge on Frontend Mentor]((https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ)). This project focuses on mastering clean HTML structure, custom CSS variables, and modern layout spacing using Flexbox.

## Overview

### The challenge

Users should be able to:
- See hover and focus states for all interactive elements on the page.
- View the optimal layout depending on their device's screen size (Responsive Design).
- Experience perfectly centered typography and layouts using modern CSS alignment properties.
